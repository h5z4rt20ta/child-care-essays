# 【仁德科普】偷走视力的小偷——糖尿病眼底病变

> 更新时间：2026-09-17 (UTC+8)

**患者小吴**

医生，我今年34岁，得糖尿病十来年了，这段时间觉得看东西比之前模糊了，这是咋回事呢？

**眼科**

**赖晓娟医生**

糖尿病的表现除了血糖升高外，所引起的并发症尤其需要重视和预防。比如糖尿病引起的白内障、糖尿病性视网膜病变、继发性青光眼三大类眼部疾患，都会对不同程度地对视力产生影响。

**患者小吴**

哎呀，怪不得，我有个嬢嬢也是糖尿病，这段时间打麻将喊她，她都不来，说她连麻将都看不清了。我以后会不会向她一样连麻将都看不清了。

**眼科**

**赖晓娟医生**

一旦被确诊糖尿病，就应该开始关注眼健康。因为除白内障外，其他两类疾病进展均不可逆。

其中，糖尿病性视网膜病变又包括眼底渗出、眼底出血、黄斑水肿等，严重者会出现视网膜前出血、视网膜脱离、玻璃体积血等，导致失明。

**患者小吴**

就是说要经常来看哈眼睛嘛。

**眼科**

**赖晓娟医生**

是的，对于早期糖尿病患者，要定期来随访。血糖控制稳定者，每半年散瞳检查1次眼底。血糖控制不稳定者，每3个月检查1次。有内眼手术史及眼底已有病变的糖尿病患者，需要缩短间隔时间。

**患者小吴**

要得，我晓得了。

医生，我还想问下，现在国家不是开放三胎了嘛，我还想生个娃娃，影响不呢？

**眼科**

**赖晓娟医生**

有糖尿病的女性应于妊娠前3个月进行眼底检查，并且在妊娠期间需要密切随访。

**赖医生：**

得了这些病该怎样治疗呢？

**眼科**

**赖晓娟医生**

最关键的治疗还是控制好血糖，同时控制好血压、血脂（控制“三高”），必须遵医嘱服药。清淡饮食、适量运动、戒烟等健康的生活方式是控制好三高的基础。

一旦发现病变，可进一步接受视网膜荧光造影检查，如眼底出现无灌注区等病变，就要根据病情积极接受眼底激光治疗及（或）眼球注射抗新生血管内皮生长因子治疗，防止疾病进一步恶化。

**患者小吴**

哦，晓得了，晓得了，以后我一定按时来复查。

回去我也跟我那个嬢嬢说，喊她来医院看哈，再耽误她怕以后连我都看不见了。谢谢你哈，赖医生。

**谈在最后**

近年来，随着我国糖尿病患者人数的激增，糖尿病眼病的患者的数量也明显增加，且呈年轻化趋势。

**根据粗略统计：**

患糖尿病2年~3年的患者开始出现眼底视网膜病变；

5年~10年的患者约有1/4合并眼底视网膜病变；

15年以上的患者该比例高达2/3。

即便如此，由于患者通常为老年人，且糖尿病眼病并不致命，因此并没有得到公众足够重视，多数患者就诊时已到疾病晚期，错失治疗最佳时期。

10月15日是国际盲人节，在全社会关注视力障碍人群的同时，我们也特别提醒患有糖尿病的患者，重视血糖控制，定期到医院检查眼底情况，让“视界”清晰不受限。
